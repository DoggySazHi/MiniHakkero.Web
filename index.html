How do I build this thing?

Only care about the 3D printed model? Click here to download the latest 3MF file. Open it in your favorite slicer and print it.

Need help assembling it?

Check out the GitHub repository for assembly instructions. But as a TLDR:

  • Print all plates in the 3MF file. Ensure your filament is dry, as some tolerances are tight.
  • If you're using wood filament, stain the printed parts and let it dry for a day before assembling.
  • Pay attention to how you're assembling the iris mechanism - you may want to use the wire version if you don't want to risk snapping plastic pins.

Want to also build the electronics? Check out the PCB and firmware repositories.

Need help with the electronics?

Take any Raspberry Pi Pico (real or clone - if you have the 2, you probably should build it) and drop the UF2 file from the firmware repository onto it while holding down the BOOTSEL button.

For the PCB, just send the ZIP file from the PCB repository to your favorite PCB manufacturer. Make sure you select 0.8 mm board thickness.

When assembling the electronics, my recommendations are as follows:

  • Start with the Pico side of the PCB, then once everything is down, hand-solder the WS2812B LEDs.
  • The USB-C port and the MAX98357A amplifier are the most difficult components to solder. Try those first, especially if you don't have a hot plate.
  • The MAX98357A can be replaced with an off-the-shelf breakout, if you don't want to deal with it.
  • Everything else should be straightforward to solder with a fine-tip soldering iron.
Make sure you continuity check as you go, especially with the USB-C port. Once the Pico side is soldered (before the LEDs), plug in the Pico and check if you get serial/debug output.

Remember to also attach copper/aluminum tape to the Mini Hakkero body for the capacitive touch sensor(s).
